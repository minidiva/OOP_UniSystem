## 📖 Overview

**University Student Portal** is an academic software development project focused on applying object-oriented programming principles to a university-related system.

The project was created to explore how a larger application can be organized through classes, objects, and their interactions, with an emphasis on maintainability, separation of responsibilities, and structured code.

Rather than treating OOP concepts as isolated exercises, this project provides an opportunity to apply them within a shared application.

## 🎯 Project Objectives

The primary objectives of this project were to:

- Practice object-oriented software design.
- Model application components using classes and objects.
- Organize code into logical, maintainable structures.
- Develop practical Java programming skills.
- Gain experience building and improving a multi-component application.

## 🧠 Object-Oriented Programming

The project was developed with a focus on the fundamental concepts of OOP:

| Concept | Purpose |
|---|---|
| **Encapsulation** | Organizing data and behavior within classes |
| **Abstraction** | Managing complexity through clear interfaces |
| **Inheritance** | Understanding relationships between related classes |
| **Polymorphism** | Designing flexible interactions between objects |

These concepts formed the theoretical foundation of the coursework. Their specific implementations can be explored in the source code.
